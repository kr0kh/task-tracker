Task Tracker

Серверная часть приложения для постановки и контроля рабочих задач.

Работа с данными выполняется через REST API:

  • GET /api/health - проверка работоспособности сервиса
  • POST /api/auth/login - получение токена доступа
  • GET /api/tasks - список задач
  • GET /api/tasks/:id - задача по идентификатору
  • POST /api/tasks - создание задачи
  • PATCH /api/tasks/:id - изменение задачи
  • DELETE /api/tasks/:id - удаление задачи
