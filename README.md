# Task Tracker - серверная часть

Учебный проект: серверная часть веб-приложения для управления задачами
(УП.03.01, темы 1-3). Клиентская часть - минимальный интерфейс в папке public.

## Требования
- Node.js 18 или новее
- MySQL 8.0

## Установка
1. `npm install` - установка зависимостей
2. `mysql -u root -p < db/schema.sql` - создание структуры базы данных
3. `mysql -u root -p task_tracker < db/seed.sql` - наполнение тестовыми данными
4. `cp .env.example .env` - создание файла окружения, затем указать свои значения
5. `npm start` - запуск сервера на порту 3000
6. `npm run check` - проверка работоспособности эндпоинтов

## Переменные окружения
| Переменная | Назначение | Пример |
| --- | --- | --- |
| PORT | порт сервера | 3000 |
| DB_HOST | адрес сервера БД | localhost |
| DB_PORT | порт БД | 3306 |
| DB_USER | пользователь БД | tracker_user |
| DB_PASSWORD | пароль пользователя БД | - |
| DB_NAME | имя базы данных | task_tracker |
| JWT_SECRET | секретный ключ подписи токенов | - |
| JWT_EXPIRES_IN | срок действия токена | 2h |

## Структура проекта
- `db/` - скрипты создания структуры и наполнения базы данных
- `src/routes/` - маршруты REST API
- `src/middleware/` - проверка токена, прав доступа и обработка ошибок
- `src/services/` - формирование CSV и расчёты для отчётов
- `scripts/` - скрипты проверки работоспособности
- `public/` - клиентская страница
